# 자료변환기 실습 교재

https://legoschool.github.io/pkos-textbook/

흩어진 자료(한글·워드·PPT·엑셀·PDF·사진·압축)를 마크다운으로 바꾸는 파이썬 도구를, 설치부터 변환·결과 읽기·코드로 직접 쓰기까지 실제 실행 화면으로 따라 하는 15블록 교재입니다.

- `index.html` — 교재
- `downloads/pkos-converter.zip` — 도구 코드 (MIT 라이선스)
- `downloads/sample-data.zip` — 실습 자료 17개 (이름·전화번호 등은 모두 지어낸 것)
- `img/` — 화면 사진

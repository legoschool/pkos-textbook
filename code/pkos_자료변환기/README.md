# 자료 변환기

흩어진 자료를 **파일 이름과 형식에 상관없이** 마크다운으로 바꿉니다.

한글·워드·PPT·엑셀·PDF·사진·웹문서·압축파일을 폴더째로 넣으면, AI와 웹이 읽을 수 있는
`.md` 묶음과 목차가 나옵니다. **여러 번 돌리는 도구**입니다 — 자료가 늘면 다시 돌리세요.
바뀐 것만 새로 만들고 목차는 이어서 씁니다.

> PKOS(개인지식운영체계) 프로젝트 · `pkems_pdf_변환` 의 다음 판
> 처음이라면 실습 교재부터 보세요: https://legoschool.github.io/pkos-textbook/ (설치부터 변환까지 화면 사진과 함께)

## 처음 한 번

**`설치.cmd` 를 더블클릭하세요.** 파이썬을 찾고, 없으면 설치를 권하고, 라이브러리를 깔고,
제대로 됐는지 확인까지 합니다.

제대로 도는지 스스로 검사하려면:

```bash
python pkos.py --자가진단
```

시험 자료를 새로 만들어 변환하고 **126가지**를 판정합니다(1~2초). 다른 PC로 옮긴 뒤,
또는 코드를 고친 뒤 꼭 돌려 보세요.

---

## 쓰는 법

가장 쉬운 방법은 변환할 폴더를 **`변환하기.cmd` 위로 끌어다 놓는 것**입니다.
먼저 훑어 보여주고, `y` 를 누르면 변환합니다.

명령창에서는:

```bash
python pkos.py "D:\흩어진자료" --훑기
```
변환 없이 무엇이 있는지만 봅니다. 이름과 속이 다른 파일, 지난번 뒤로 바뀐 파일 수도 알려 줍니다.

```bash
python pkos.py "D:\흩어진자료" --맛보기 20
```
앞 20개만 시험 변환.

```bash
python pkos.py "D:\흩어진자료"
```
전체 변환. 결과는 원본 옆 `_변환결과` 에 생깁니다.

```bash
python pkos.py "이상한파일" --확인
```
파일(또는 폴더)의 정체만 알려 줍니다.

`python 변환.py …` 로 불러도 똑같이 동작합니다.

### 다시 돌릴 때

| 상황 | 어떻게 되나 |
|---|---|
| 아무것도 안 바뀜 | 파일을 **열지도 않고** 끝남 (자료 215개·289MB 기준 약 1초) |
| 파일을 추가·수정함 | 그 파일만 다시 변환, 목차는 이어서 씀 |
| 원본을 지움 | 목차 맨 아래 '원본이 사라진 문서'로 옮김. 변환본은 지우지 않음 |
| 도구를 고침(판 번호가 바뀜) | 원본이 그대로여도 다시 변환해 고친 내용을 반영 |
| `--글자인식` 을 켬 | 전에 못 읽은 스캔 PDF·사진을 다시 시도 |
| `--다시` | 전부 다시 만듦 |

## 결과물

```
_변환결과/
├── INDEX.md                 사람이 읽는 목차 (갈래별)
├── _index.json              변환 기록 — AI·웹이 읽는 목록이기도 함
├── _오류.md                  못 읽은 것과 이유   (프로그램 오류는 _오류_상세.log)
├── _중복.md                  내용이 같아 건너뛴 사본
├── _개인정보_보고서.md
├── assets/<결과 경로>/       문서마다 따로 두는 그림 폴더
├── 블로그/                   블로그 백업 PDF → 글 단위 (백업끼리 겹치는 글은 한 번만)
└── (원본 폴더 구조)/….md
```

각 `.md` 머리말:

```yaml
---
title: "수업모형의 의미와 선정전략"
date: 2025-03-14
source: "03_수업자료/강의안.pptx"
format: "pptx"
format_label: "파워포인트"
group: "발표"
detected: "내용(ZIP 안에 ppt/presentation.xml)"
ext: ".pptx"
sha256: "3f9a1c22b80d4e77"
chars: 8412
images: 14
tags: []
---
```

`detected` 에 **어떻게 판별했는지**가 남습니다. 결과가 이상할 때 이 줄부터 보세요.
본문의 그림은 **원래 있던 자리에** 링크로 들어갑니다.

## 무엇을 읽나

| 갈래 | 형식 |
|---|---|
| 한글 | `.hwp` `.hwpx` `.hml` (서식파일 `.hwt` 포함) |
| 워드 | `.docx` `.docm` `.dotx` · 옛 `.doc` |
| 발표 | `.pptx` `.pptm` `.ppsx` `.potx` · 옛 `.ppt` |
| 표 | `.xlsx` `.xlsm` `.xltx` · 옛 `.xls` · `.csv` `.tsv` |
| 오픈도큐먼트 | `.odt` `.ods` `.odp` |
| PDF | 글자 PDF · 블로그 백업 PDF(글 단위로 나눔) · 스캔 PDF(글자 인식을 켤 때) |
| 글 | `.txt` `.md` `.html` `.xml` `.json` `.ipynb` `.srt` `.vtt` `.smi` · 소스코드 |
| 그림 | `.jpg` `.png` `.gif` `.webp` `.bmp` `.tiff` `.heic` `.svg` |
| 압축 | `.zip` — 풀어서 안까지 (한국 윈도우식 한글 이름도 깨지지 않음) |

**확장자는 믿지 않습니다.** `문서1.pdf` 가 실은 워드여도, 확장자가 아예 없어도 내용을 보고 읽습니다.

### 읽는 방식에서 신경 쓴 것

- **워드** — 표를 본문 제자리에, 글상자·머리글·각주까지
- **PPT** — 슬라이드 제목을 `## 3. 제목` 구획으로, 그룹으로 묶은 도형 안의 글, 표, 차트 데이터, 발표자 노트
- **엑셀** — 날짜는 날짜로, 정수는 정수로(`3500000.0` 이 아니라 `3500000`), 쓰지 않은 오른쪽 열은 버림
- **한글 hwpx** — 서식이 바뀌는 곳에서 낱말이 끊기지 않게, 표 속 표가 바깥 칸을 덮어쓰지 않게, 그림은 제자리에
- **PDF** — 쪽 표시(`<!-- 쪽 3 -->`), 줄 끝에서 끊긴 문장을 이어 붙임, 그림은 그 쪽에
- **옛 형식** — 마이크로소프트 공개 명세대로. `.doc` 는 문단 속성을 풀어 표를 되살리고, `.ppt` 는 슬라이드 마스터·내부 태그·연결 경로가 섞이지 않게
- **오픈도큐먼트** — 한글에서 내보낸 ODT 는 표가 '문단 속 틀 안의 글상자'에 있어 거기까지 따라감

## 사진과 스캔 문서

기본값은 **글자 인식(OCR) 꺼짐**입니다. 사진은 `assets` 에 보관하고 찍은 날짜·기기(EXIF)를
기록합니다. 이름이 `IMG_0001` 같으면 제목을 `사진 2019-07-21` 로 짓습니다.

켜려면:

```bash
winget install UB-Mannheim.TesseractOCR
```
설치할 때 Korean 을 고르세요. 그다음:
```bash
pip install pytesseract pillow
```
```bash
python pkos.py "D:\사진" --글자인식 tesseract
```

`--글자인식 claude` 는 표·손글씨까지 가장 잘 읽지만 **이미지가 외부로 전송되고 비용이 듭니다.**
개인정보가 담긴 자료에는 쓰지 마세요. (`pip install anthropic` · 인증은 `ANTHROPIC_API_KEY` 또는 `ant auth login`)

스캔 PDF 와 글자 PDF 구분: 뷰어에서 글자가 **드래그로 선택되면** 글자 PDF 입니다.

## 개인정보 자동 가리기

기본값 **켜짐**. 주민등록번호·전화번호·이메일·계좌번호·카드번호·이름·주소·생년월일·차량번호를
가리고 `_개인정보_보고서.md` 에 무엇을 어떻게 바꿨는지 남깁니다.

> ⚠ **보고서에는 가리기 전 원본이 그대로 들어 있습니다.** 확인한 뒤 지우거나 절대 공유하지 마세요.
> `--보고서원본숨김` 을 붙이면 건수만 남습니다.

탐지 규칙은 학교 업무 문서로 다듬은 기존 필터(`privacy.py`)를 쓰고, 대학원·수업 자료에서
드러난 문제는 `privacy_guard.py` 에서 덧씌워 고쳤습니다.

| 문제 | 예 | 처리 |
|---|---|---|
| 문헌 번호를 카드·주민번호로 | `doi.org/10.1177/1365480216659733` · `10.1023/A:1022193728205` | 주소·DOI·ISBN 의 일부면 가리지 않음 |
| 표 속 숫자를 카드번호로 | `2016 2017 2018 2019` | 숫자 나열이면 아님. '카드' 표시가 없으면 검증식(Luhn) 통과해야 가림 |
| 주소 속 날짜를 생년월일로 | `…?date=2019-03-15&…` | 가리지 않음 |
| 흔한 낱말을 이름으로 | `파일 이름 설정` → `설*` | 같은 낱말이 `설정에서`·`설계하는` 처럼 쓰이면 이름 아님 |
| 인용 속 저자를 이름으로 | `이상수(2024)` → `이*수(2024)` | 인용 꼴로 나오는 이름은 공개된 저자로 보고 가리지 않음 |
| 계좌번호를 놓침 | `계좌: 신한 110-…` · `계좌번호(경남은행) 207-…` | 은행 이름이 끼어도 가림 |

본문에서 확인된 이름은 **제목에서도** 가립니다. 파일·폴더 **이름**은 바꾸지 않고 보고서에 알립니다.
**완벽하지 않습니다. 공개 전에는 반드시 직접 점검하세요.**

## 옵션

| 옵션 | 하는 일 |
|---|---|
| `--훑기` | 변환 없이 현황만 |
| `--확인` | 파일·폴더의 정체만 |
| `--맛보기 N` | 앞 N개만 |
| `-o <폴더>` | 결과 위치 |
| `--다시` | 전부 다시 만들기 |
| `--글자인식 tesseract` / `claude` | 사진·스캔 PDF 글자 읽기 |
| `--개인정보끄기` · `--보고서원본숨김` | 개인정보 처리 |
| `--그림안꺼냄` · `--압축안열기` · `--중복허용` · `--블로그분리끄기` | 기능 끄기 |
| `--최대MB 500` | 큰 파일 한도 (기본 300) |
| `--자가진단` · `--점검` | 스스로 검사 · 라이브러리 확인 |

## 구성

| 파일 | 역할 |
|---|---|
| `설치.cmd` · `변환하기.cmd` | 처음 설치 · 끌어다 놓기 실행 (**순수 영문 파일**) |
| `pkos.py` · `변환.py` | 실행 진입점 (같은 것) |
| `engine/sniff.py` | **내용으로 형식 판별** |
| `engine/readers.py` | 형식별 읽기 · 그림 제자리 저장 |
| `engine/oldoffice.py` | `.doc` `.ppt` `.xls` |
| `engine/images.py` | EXIF · 그림 형식 바꾸기 |
| `engine/ocr.py` | 글자 인식 엔진 |
| `engine/privacy_guard.py` | 개인정보 필터 보정 |
| `engine/pipeline.py` | 훑기 → 변환 → 기록·목차 |
| `engine/fsutil.py` · `engine/mdutil.py` | 긴 경로·링크·머리말 · 마크다운 표 |
| `tests/` | 자가진단 (`run_tests.py` · `make_fixtures.py` · `fixtures/`) |

기존 `pkems_pdf_변환` 에서 가져와 **손대지 않은** 것: `engine/readers_legacy.py`(한글 `.hwp`
이진 해석), `engine/privacy.py`, `engine/blogpdf.py`.

## 파이썬에서 직접 쓰기

```python
from engine import sniff, Converter, Settings

k = sniff("이상한파일")
print(k.fmt, k.label, k.mismatch, k.why)

c = Converter(Settings(src=r"D:\흩어진자료", out=r"D:\결과"))
c.scan()              # 현황만
c.run(limit=20)       # 20개만
c.run()               # 전체
```

## 알려진 한계

| 한계 | 내용 |
|---|---|
| 스캔 문서·사진 | 글자 인식을 켜야 읽음 |
| `.hwp`(이진) 그림 | 제자리가 아니라 문서 끝에 모음 (hwpx·hml·워드·PPT·PDF 는 제자리) |
| `.doc` `.ppt` | 글·표 위주. 그림은 꺼내지 않음. `.doc` 에서 여러 줄짜리 칸은 줄바꿈으로 합침 |
| 표 | 병합 칸은 첫 칸에만 값 |
| 원본 속 상대 링크 | 마크다운·HTML 안의 상대 링크는 원래 위치 기준이라 옮기면 깨질 수 있음 |
| 구글 문서 | 온라인에만 있어 못 읽음 — `.docx` 등으로 내려받기 |
| 보안(DRM) 파일 | `개설강좌.xlsx.pia` 같은 것은 못 읽음 — 이유를 안내 |
| `.7z` `.rar` · `.rtf` · `.epub` | 읽지 않음 — 안내만 |
| 배포용·암호 한글 | 못 읽음 — 이유를 안내 |
